AI Memory Vault Privacy Policy

Effective date: July 3, 2026

Overview

AI Memory Vault helps users save and reuse encrypted memory notes from AI chat pages. The extension and web app are designed so memory content is encrypted before it is stored.

Data We Collect

AI Memory Vault may process the following user data to provide its core features:

  • Email address for account sign-in.
  • Authentication information required to sign in to the user's vault account.
  • Vault passphrase entered by the user. The passphrase is used locally for encryption and decryption.
  • AI chat text or selected page content when the user chooses to preview, save, or reuse memory context.
  • Extension settings, such as saved account/session state and preferred vault settings.

How Data Is Used

User data is used only to provide AI Memory Vault's single purpose: saving encrypted memory notes from AI chat pages and retrieving approved memories back into supported AI chat pages.

Encryption

Memory content is encrypted in the user's browser before storage. The vault passphrase is not sent to Supabase or to the extension developer. If a user forgets the vault passphrase, encrypted memory content cannot be recovered.

Data Sharing

AI Memory Vault does not sell user data. User data is not transferred to third parties for advertising, unrelated purposes, creditworthiness, or lending decisions.

Third-Party Services

The hosted version uses Supabase for authentication and encrypted database storage. Supabase stores account data and encrypted vault rows needed to run the service.

User Control

Users choose when to preview chat content, save memories, approve memories, search memories, export decrypted memories, or delete saved memories.
